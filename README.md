## Project name
ai-interview-copilot

## Year

## Purpose
AI-powered mock interview co-pilot with resume parsing and personalized Gemini question generation.

## Features
- PDF resume parsing with structured section extraction
- Role-based question generation (GenAI, Frontend, Backend, Full Stack, ML, DevOps, and more)
- Answer evaluation and end-of-session coaching via Gemini
- Transcript cleanup and budget-aware API usage
- Observability hooks for logging and OpenTelemetry
- Frontend:** React, TypeScript, Vite, Tailwind CSS

## Tech Stack used
- React
- Vite
- TypeScript
- Tailwind CSS
- Axios
- FastAPI
- pypdf
